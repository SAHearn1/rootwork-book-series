# Debug Playbook — rootwork-book-series

> Tier 3 repo — book series content repository.

## Common Failure Patterns

| Symptom | First Check | Likely Cause |
|---------|------------|---------------|
| Build fails | Build logs | Missing dependency |
| Links broken | href paths | Wrong path or renamed file |
| Images missing | src paths | Missing asset |
| Series navigation broken | Cross-book links | Path reference incorrect |

## Content Integrity
Do not modify authored content without explicit human approval.
